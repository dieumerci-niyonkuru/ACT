# ACT Website — Photo Guide

Which photo appears where, and the exact file to replace to change it.
To swap a photo: put your new image in the same folder, give it the **same file name**,
and it appears automatically — no code editing needed. Keep a similar shape (portraits
roughly square, banners wide) so the layout stays tidy.
